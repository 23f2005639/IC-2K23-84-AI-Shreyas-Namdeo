# Shared datasets

- `roads.json`: small directed graph, authored for Lab2. Edge costs are
  positive; the supplied heuristic is admissible for goal F.
- `placement.csv`: synthetic teaching records for Lab3, with missing values
  and a duplicate; not real student data or a benchmark.
- Lab5 uses scikit-learn's bundled Iris dataset and exports `iris.csv` here.
- Lab6 creates synthetic curves in memory.
- Lab7 uses scikit-learn's bundled 8x8 digits dataset; no download required.
