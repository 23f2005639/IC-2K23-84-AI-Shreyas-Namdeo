# Documentation

`algorithm-flowcharts/` and `architecture-diagrams/` contain simple Mermaid sources.

After recording experiment results, run `python3 docs/build_reports.py` to
create `performance-analysis.pdf` and `mini-project-report.pdf` here.
The report builder reads existing metrics; it never runs experiments.
Missing measurements are marked pending. PDFs have not been generated.
Presentation is optional and not included.

For later submissions, use separate experiment branches and meaningful commits.
Add Mid-Sem / Final-Submission tags when those milestones are reached.
