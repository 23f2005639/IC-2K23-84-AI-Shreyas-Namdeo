# Repository style

Use short, readable Python with meaningful problem-specific variable names.
Keep functions reusable, validate inputs and follow PEP 8.
Use brief docstrings and only necessary comments. Keep READMEs concise.
Store experiment outputs in each lab's outputs/ folder, shared data in
datasets/ and trained weights in models/.
Do not execute experiments or tests unless the user asks.
Do not invent performance measurements or screenshots.
